# 同人誌 vol.1 実践用Modの雛形

オーストラリア（AST。AUSはオーストリア）で使用する教材用の最小構成です。
実機検証はまだ行っていません。完成版のModではありません。

## 流れ

1. 専用NF `AST_DJ_union_proposal` を取得。
2. 1日後のイベント `ast_dj.1` の選択肢でハンガリーを併合。
3. 政治力50を使って国家形成デシジョンを実施。
4. 国名を変更し、国民精神を付与。6時間後にニュースを発生。

NFは教材専用ツリーに切り替える方式です。既存のオーストラリアのツリーへの追記は行っていません。
併合後の中核州追加、独立処理、国旗・画像、拒否ルート、厳密な領有条件は未実装です。
数値・文章は例示用です。ニュースは通知のみで、国家形成の効果はデシジョンに置いています。

## ファイル

- `common/national_focus/ast_nf_v1.txt`: ツリーとNF
- `events/ast_event_v1.txt`: 併合イベントとニュース
- `common/decisions/categories/ast_decision_c_v1.txt`: カテゴリ
- `common/decisions/ast_decision_v1.txt`: 国家形成
- `common/ideas/ast_ideas_v1.txt`: 国民精神
- `localisation/japanese/ast_v1_l_japanese.yml`: 日本語。UTF-8 BOM付き、空白で字下げ

## ランチャー登録

`descriptor.mod`だけではランチャー登録は完了しません。
ランチャーで作成済みのローカルModへ内容をコピーするか、外部の登録用 `.mod` の
`path`をこのディレクトリに合わせてください。登録ファイルは自動変更していません。
`supported_version`は実機検証した版を確認してから設定してください。

## 動作確認

他のModを外し、日本語・1936年開始・オーストラリアで新規ゲームを開始します。
上の流れを順に実施し、ツリー、日本語、併合、デシジョン、国名、国民精神、ニュースを確認してください。
自作ID（`AST_DJ`と`ast_dj`）に関する `logs/error.log` のエラーも確認します。
ハンガリーが存在しない場合、NF完了後に消滅した場合、形成後の再表示も確認してください。
現在の形成条件は簡略化しているため、併合後に領土を失ってもフラグがあれば実施できます。
