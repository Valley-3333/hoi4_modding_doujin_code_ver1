# HoI4 Mod制作入門 vol.1 実践用Mod

オーストラリア（AST）でハンガリーとの統合を進め、オーストラリア＝ハンガリーを形成する教材用Modです。ASTはオーストラリア、AUSはオーストリアです。

本編の実装と実機検証は著者により完了しています。おまけの新規State追加は未実装です。
`descriptor.mod`の対応バージョン表記は`1.19.*`です。これは設定値であり、個々のパッチ・DLC構成すべての検証を示すものではありません。

## 導入

1. リポジトリをダウンロードし、ZIPの場合は展開します。
2. Paradox LauncherでローカルModを作成します。
3. 生成されたModフォルダへ、本リポジトリの`common`、`events`、`gfx`、`interface`、`localisation`をコピーします。ランチャーが生成した`descriptor.mod`はそのまま使用できます。
4. 作成したModをプレイセットで有効にし、日本語・1936年開始・オーストラリアで新規ゲームを開始します。

リポジトリのフォルダを直接使う場合は、ランチャー登録用の外部`.mod`ファイルの`path`をそのフォルダに合わせてください。リポジトリ内の`descriptor.mod`だけではランチャー登録は完了しません。
教材の動作を確認するときは、他のModを無効にしてください。

## 本文の説明順と実装内容

専用NFツリーをオーストラリアに適用します。既存ツリーへの追記ではありません。

1. **提案と返答 — `AST_DJ_unite_with_hungary`**  
   存在し、どの国の傀儡でもないハンガリーに、NF完了の1日後に提案イベントを送ります。承諾・拒否の1日後にAST側で返答イベントが発生し、選択肢を実行すると、承諾時は傀儡化、拒否時は傀儡化の戦争目標を得ます。現在のAI選択設定は承諾100・拒否0です。
2. **即時併合 — `AST_DJ_annex_hungary_immediate`**  
   ASTの傀儡となったHUNを、NF完了の1日後のイベントで併合します。軍の移管と併合済みフラグの設定を行います。
3. **段階的統合 — `AST_DJ_take_long_time`**  
   即時併合と排他的なNFです。HUNを傀儡として残し、安定度を10ポイント加えます。
4. **現地政府との協力・投資**  
   `AST_DJ_cooperate_with_local_government`と`AST_DJ_invest_in_hungary`は、即時併合・段階的統合のいずれかを完了すると進められます。協力NFは、段階的統合済みでHUNがASTの傀儡なら併合デシジョンの案内を表示し、それ以外ではAST所有のHUN中核州の迎合度を30ポイント加えます。投資NFは、HUNがASTの傀儡ならHUN所有、それ以外ならAST所有のHUN中核州を対象に、各州の建設スロットを1増やし、民需工場1の建設を追加します。
5. **併合デシジョン・国家形成・ニュース**  
   協力NF完了後、ASTの傀儡HUNを政治力50で併合できます。国家形成デシジョン自体の政治力消費は0です。形成すると国名を変更し、国民精神を付与し、HUN中核州すべてにASTの中核を追加します。この中核追加はAST所有州だけに限定していません。6時間後にニュースを通知します。
6. **エミュー君主 — `AST_DJ_Having_His_Majesty_Emu_as_Sovereign`**  
   国家形成後に表示され、協力・投資の両NF完了が必要です。ロッド・ハルに国家指導者の役割を追加して名前を変更し、国民精神を強化版へ交換します。強化版には海軍装備・航空機の研究補正と、小銃・指定した航空機系装備の生産コスト軽減があります。

## 国家形成の条件

次の共通条件を満たす必要があります。

- 本Modのイベントまたはデシジョンによる併合済みフラグがある。
- ASTがHUN中核州を少なくとも1州領有している。
- まだ国家形成を実施していない。

加えて、次のどちらかを満たす必要があります。

- 段階的統合NFと現地政府との協力NFを完了している。
- ASTが領有するHUN中核州すべての迎合度が35を超えている（35ちょうどは不可）。

形成後は形成済みフラグによってカテゴリを非表示にし、NFツリーの表示を更新します。国名変更はcosmetic tagを使い、独立した別国家タグへの変更は行いません。

## ファイル

| ファイル・フォルダ | 内容 |
|---|---|
| `common/national_focus/ast_nf_v1.txt` | 専用ツリーと6個のNF |
| `events/ast_event_v1.txt` | 提案、承諾・拒否の返答、即時併合のイベント |
| `events/ast_news_v1.txt` | 国家形成のニュース |
| `common/decisions/categories/ast_decision_c_v1.txt` | デシジョンカテゴリ |
| `common/decisions/ast_decision_v1.txt` | 併合・国家形成デシジョン |
| `common/ideas/ast_ideas_v1.txt` | 形成時と強化後の国民精神 |
| `interface/ast_icons_v1.gfx` | 画像とスプライト名の対応 |
| `gfx/interface/ideas/` | 国民精神のDDS画像2点 |
| `localisation/japanese/ast_v1_l_japanese.yml` | 日本語表示。UTF-8 BOM付き |
| `descriptor.mod` | Modの名称・対応バージョンなど |

ローカライズは、提案・返答、即時併合、段階的統合、協力・投資、デシジョン・国家形成・ニュース、エミュー君主の順に並べています。

## 検証状況と今後の変更時の確認

本編は著者による実機検証済みです。コードを変更した場合は、変更したルートのNF、イベント、日本語表示、併合、形成条件、国民精神、指導者、ニュースを確認してください。
意図した動作にならない場合は、`logs/error.log`で自作ID（`AST_DJ`、`AST_HUN`、`ast_dj`）に関するエラーを確認できます。

新規Stateの追加は今後のおまけ用作業です。本文の執筆・校閲は継続中です。
